# Nemotron H v1 support removed

{/* Keep this notice for previews that use navigation from main. */}

Support for Nemotron H v1 (4B, 8B, 47B, and 56B) has been removed from Megatron Bridge. The former conversion and training instructions no longer apply.

See the [family overview](index.mdx) for supported Nemotron 3 and 3.5 models.
