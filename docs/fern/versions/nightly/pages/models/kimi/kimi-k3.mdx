# Kimi K3

{/* MODEL GUIDE: MANUAL */}

<a id="verified-kimi-k3"></a>

[Kimi K3](https://huggingface.co/moonshotai/Kimi-K3) is a sparse MoE model from
Moonshot AI. Megatron Bridge supports its language backbone through
`KimiK3Bridge` and the config + builder API.

## Implementations

- **Bridge implementation:** the default, unoptimized implementation uses Core's
  `HybridModel` with Bridge-owned KDA, MLA, SiTU, latent MoE and attention residual
  layers. HF configuration determines the architecture and weight mapping.
- **Optimized implementation:** native Kimi K3 components are available on the
  Megatron-Core `dev` branch. Integration and performance work are tracked in
  [#6451](https://github.com/NVIDIA-NeMo/Megatron-Bridge/issues/6451).

## Configuration and conversion

Use `AutoBridge.from_hf_pretrained(...).get_model_config()` to obtain
`KimiK3ModelConfig`. The standard builder constructs the model. HF import/export
supports language-backbone weights, including MXFP4 expert conversion; unchanged
multimodal weights pass through during export.

Each HF block maps to an attention layer followed by a dense or expert layer.
Pipeline stages contain complete HF blocks. Set `model.pipeline_block_counts`
to override their distribution.

## Recipes

- `kimi_k3_pretrain_config`: HF-derived BF16 pretraining configuration with
  TP4/PP4/EP128, full recomputation, 8K sequences and distributed Adam. Set
  `KIMI_K3_HF_PATH` for a local snapshot and supply tokenized data and a checkpoint.
- `kimi_k3_pretrain_64gpu_gb300_bf16_proxy_config`: reduced 24-block BF16/Adam
  proxy with PP1/EP64, random initialization, mock data and forced routing.
  This is not the MXFP8/MoK/Muon performance configuration.

## Supported scope

The default implementation supports unquantized language-backbone training.
Cached generation, CP/dynamic CP, VPP, MTP, nonzero hidden dropout, CUDA graphs,
offloading and overlapping expert communication are unsupported. Keep DDP
parameter/gradient overlap disabled. TP with MoE requires sequence parallelism,
which cannot be combined with distributed saved activations.

Full-model convergence, performance, multimodal execution, arbitrary padding
masks and quantized training remain outside the supported scope. Follow
[#6451](https://github.com/NVIDIA-NeMo/Megatron-Bridge/issues/6451) for progress.
