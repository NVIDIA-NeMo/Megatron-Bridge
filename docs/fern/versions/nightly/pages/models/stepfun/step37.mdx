# Step-3.7-Flash

[Step-3.7-Flash](https://huggingface.co/stepfun-ai/Step-3.7-Flash) is a multimodal model from StepFun. Its text backbone has the same architecture as Step-3.5-Flash. Megatron Bridge registers the `Step3p7ForConditionalGeneration` architecture through a dedicated Step-3.7 bridge.

## Architecture Notes

- The vision tower is Perception-Encoder G/14 followed by two Conv2d downsamplers and an `align_projector` linear layer that maps vision features to the text hidden size.
- Step-3.7-Flash requires Megatron-LM changes that are not yet in the pinned submodule. The examples README describes how to switch to the required Megatron-LM branch.
